Playback, library, download, and background-service stability improvements, with adaptive haptics and refreshed music visuals.

### Playback

- Start music with one tap after dismissing the player, and keep the latest request while the playback service starts.
- Fix compatibility-engine Next/Previous, recursive pause callbacks, end-of-queue behavior, and sleep-timer volume restoration.
- Cancel stale artwork work and keep updates attached to the correct player and song.
- Load uncached video metadata in the background and release metadata readers reliably.
- Improve adaptive video/music haptics, route-specific tuning and previews, music sound profiles, and visual themes.
- Reduce unnecessary library-row recomposition during live music visualization.

### Library and file actions

- Preserve the original file URI when renaming or inspecting media, handle duplicate delete selections, and protect existing rename destinations.
- Complete app-owned trash operations directly when permitted; continue using Android consent for files that require it.
- Add independent, non-destructive removal from Recently Added and Continue Watching, including Undo.
- Improve folder materials, context menus, navigation feedback, and footer touch isolation.

### Downloads and streaming

- Keep concurrent progress, pause, completion, and cancellation updates consistent.
- Route torrent reads only to the selected local movie, keeping subtitle and unrelated file requests separate.
- Handle read boundaries and interruptions, and enforce download-directory containment.
- Track sequential downloads in notifications, release resources when paused, and restart the service when resuming.
- Respect Wi-Fi-only download settings and stop safely when Android ends the foreground-service time budget.
