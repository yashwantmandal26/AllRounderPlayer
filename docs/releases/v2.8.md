*Live DJ Vinyl Scratching, real-time song audio modulation, slim single-bar sliders, multi-shade luxury white theme, and release web portal.*

### What's new in v2.8

- **Dynamic DJ Vinyl Scratching with Live Audio Modulation:**
  - Real-time vinyl manipulation that directly modulates the currently playing song's audio rather than synthetic noise.
  - Clockwise dragging applies smooth speed and pitch acceleration ($1.0\times$ to $3.0\times$).
  - Counter-clockwise dragging smoothly tracks backwards through the playback timeline from the exact playhead position without jumping.
  - Scratch gesture physics decoupled from vertical volume and brightness sliders for zero-conflict fingertip control.
- **Slim Single-Bar Volume & Brightness Sliders:**
  - Redesigned into ultra-clean, minimalist vertical single tracks ($3.5\text{dp}$) with theme accent glow.
  - Removed percentage badges for an uncluttered modern aesthetic.
  - Automatic 2.5-second auto-fade discovery animation on entering the Music screen so users know sliders are accessible.
- **Multi-Shade Luxury White Theme UI:**
  - Modernized the Music screen in Light Theme using a 3-shade white palette (`#FFFFFF` pure snow white, `#F8FAFC` frosted pearl, `#F1F5F9` porcelain platinum).
  - Ambient album gradient wash preserved beneath subtle light overlays with high-contrast dark typography.
- **Interactive 3D Cards Web Portal (`index.html`):**
  - High-performance web portal built with 3 shades of white and soft ambient radial gradients.
  - Interactive 3D tilt cards, interactive spinning vinyl preview, inspirational music quote, developer attribution (**Yashwant Mandal**), and a big one-click direct download button for `app-release.apk`.
- **Seamless Over-The-Air Update Support:**
  - Incremented `versionCode = 40` and `versionName = "2.8"`.
  - Signed release APK built with release signing key. Existing users opening the app will automatically receive the update prompt and install over older builds without conflicts.
