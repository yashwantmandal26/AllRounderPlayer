*Gallery-style Video Zoom & Pan, Dynamic Subtitle Caption, Flicker-Free Ambient Backdrop, 1-Tap Equalizer Modes, Timestamp Remaining Time, Video Spec Badge & MyCinema Season Filtering Fixes.*

### What's New in v2.8.2

- **Video Player HUD, Controls & Spec Display:**
  - Restored circular HUD buttons on player top/bottom/options bars while keeping center playback buttons (`Prev` / `Play-Pause` / `Next`) and modal headers clean without icon circles.
  - Fixed control label alignment across the expanded toolbar (`Back`, `Playlist`, `Speed`, `Audio`, `Subtitles`, `More`).
  - Repositioned the seekbar closer to bottom controls and brought the timestamp right above the track; tapping the timestamp now toggles remaining time (`-mm:ss / hh:mm:ss`).
  - Top-left video spec badge now displays clean resolution (`8K` / `4K` / `2K` / `1080p` / `720p` / `480p`), frame rate (`24fps` / `30fps` / `60fps`), and file size (`10MB` / `2GB`).
  - Single-tapping `Equalizer` in the expanded toolbar cycles cleanly through the 4 sound modes (`Balanced` → `Bass Punch` → `Vocal Boost` → `3D Spatial`), with long-press opening detailed audio controls.

- **Gallery-Style Pinch Zoom & Pan + Video Audio/Pause Sync:**
  - Added focal-point anchored pinch-to-zoom and smooth single-finger panning across the video frame just like a gallery photo viewer.
  - Resolved audio continuing when playback is paused by synchronizing manual pause state across `VideoPlaybackManager`, lifecycle hooks, and audio focus restoration.

- **Flicker-Free Ambient Lighting & Dynamic Captions:**
  - Eliminated ambient background strobe/brightness dips via temporal EMA pixel smoothing, 2-pass spatial blur, offscreen-composited crossfading, and sequential capture-to-fade timing.
  - Replaced `Cyber Neon` with **Dynamic Caption** as the default cardless subtitle style (automatically adapting text color to your active app theme accent) and ensured `Classic Cinema` stays text-only with zero background card.

- **MyCinema & UI Polish:**
  - Fixed season filtering and episode parsing so selecting Season 2+ shows strictly matching season results instead of falling back to Season 1 packs.
  - Removed overlapping circular icon backdrops from modals, dialogs, MyCinema sheets, music, folder detail, and settings sections.
