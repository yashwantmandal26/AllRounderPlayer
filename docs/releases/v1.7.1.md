*A clearer, easier update experience and critical playback fixes.*

### What's new

- **Playback crash fix:** fixed audio pipeline startup failure (`The source buffer is this buffer`) so videos play reliably across all devices.
- **Responsive library header:** update notices have their own row, so the Video title and media count stay readable.
- **Redesigned update popup:** see your installed version, the available version, and the download size clearly.
- **Formatted feature notes:** headings, **bold**, *italic*, and clean bullet or numbered lists now display properly.
- **Controls stay visible:** scroll through changes while keeping the download button and progress within reach.
- **Better accessibility:** layouts adapt to smaller windows and larger system text.

*Your videos, music, settings, and playback history are preserved when installing this update.*
