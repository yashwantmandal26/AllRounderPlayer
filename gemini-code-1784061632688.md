# 🚀 Project: Ultimate Android Video Player App

## 👤 Role & Persona
Act as an Elite Android Developer (Kotlin) and an Expert UI/UX Designer who specializes in premium, fluid, and minimalist iOS-like interfaces for the Android ecosystem.

## 🎯 Core Objective
Develop a comprehensive architectural plan, UI/UX design guidelines, and core module code for a feature-rich Android Video Player. The app must match the robust decoding capabilities of VLC and MX Player while delivering a sleek, modern, and fluid iOS-inspired user experience (similar to Apple's native media player, Netflix, and YouTube).

## 🎨 UI/UX Requirements (iOS-Inspired)
- **Aesthetic:** Glassmorphism, smooth rounded corners, blurred dynamic backgrounds based on the currently playing video, and True Dark Mode by default.
- **Navigation:** Bottom-heavy navigation (Thumb-zone friendly), zero-click navigation feel, and minimalistic auto-hiding playback controls.
- **Gestures:** Fluid iOS-like micro-animations. Double-tap to skip (with circular ripple), swipe up/down on edges for brightness and volume, pinch to zoom, and seamless swipe-to-dismiss.
- **Playback Screen:** Clean, distraction-free immersive mode. Must include thumbnail previews on the progress bar while scrubbing (like YouTube/Netflix).

## ⚡ Core Features & Functionalities
1. **Universal Playback (VLC/KM Player inspired):**
   - Support for ALL video and audio formats (MKV, MP4, AVI, MOV, FLV, TS, OGG, etc.).
   - Hardware acceleration (HW/HW+) for smooth 4K/8K HDR playback.
2. **Advanced Subtitles (MX Player inspired):**
   - Support for multiple subtitle formats (SRT, ASS, VTT).
   - Online subtitle searching and auto-downloading.
   - Complete customization: Font size, color, background, and manual synchronization delay adjustments.
3. **Audio & Equalizer:**
   - Multi-track audio support (switch between dual audio/languages seamlessly).
   - Built-in 10-band equalizer with bass boost, virtualizer, and surround sound profiles.
4. **Multitasking & Background:**
   - Seamless Picture-in-Picture (PiP) mode (smooth transition like YouTube).
   - Background audio playback (like XPlayer/Lark Player).
5. **Network & Streaming (Nova Player inspired):**
   - Stream media via SMB, FTP, UPnP, and direct network URLs.
6. **Smart Library Management:**
   - Auto-scan, group, and organize local videos efficiently.
   - Netflix-like visual layout for movies/series (fetching metadata/posters automatically).
   - Secure private folder (PIN/Biometric protected) to hide sensitive videos.

## 🛠️ Tech Stack & Architecture
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (for building the fluid, modern, animated UI)
- **Media Engine:** Media3 (ExoPlayer) or custom libVLC integration
- **Architecture:** MVVM with Clean Architecture principles
- **Asynchronous Work:** Kotlin Coroutines & Flow
